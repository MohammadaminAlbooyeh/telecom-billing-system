# 📒 Contact Book

A simple Python-based contact book application that allows users to **add**, **view**, **update**, and **delete** contacts from a command-line interface.

## 🚀 Features

- Add new contacts with a name, phone number, and optional email.
- Update existing contact details.
- View contact information.
- Delete contacts.
- Command-line user interface with options menu.

## 🛠️ Technologies Used

- **Python 3**
- `collections.defaultdict` for efficient dictionary management
